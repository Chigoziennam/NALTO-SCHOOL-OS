Principles
Event, not catalogue

The homepage is a stage for the current drop, with live stock and a real countdown.

Loud at the door, quiet at the till

Night mode where people feel the brand. Day mode where they choose a size and pay.

Proof sells

Worn By lives inside shopping: badges on product pages and shop-the-look on every celeb photo.

Keep the promise

Waitlist perks become Circle perks on day one: early access, the early-bird discount, first look at styling.

Built for mobile data

A mid-range Android on 4G is the test phone. Video plays only when the connection can afford it.

Answers fast, a human close

The concierge handles sizing, stock and order tracking, and hands over to WhatsApp when it should.

The rest of the plan

Checkout and Paystack, the Supabase data model, the Higgsfield shot list, the stack and the roadmap are written up in the repo at yowa/BLUEPRINT.md. The main site itself is now being built in yowa/site.

Sheet 07

Drops engine

States + rulesReady
  • The countdown runs on server time, so a wrong phone clock never shows the wrong time.
  • Circle members get in first with a personal code or link. Hype drops can add a shared password.
  • Live stock per size (Supabase Realtime) and a count of people in the drop (Presence).
  • Stock is held for 15 minutes from checkout start, then released automatically (pg_cron).
  • Limits per customer, and Cloudflare Turnstile on checkout during drops to slow bots.
  • Sold out is a designed screen with restock alerts and the next drop. It never looks like an error.
  • A waiting room for very large drops comes later.
Sheet 08

AI concierge

OpenRouterReady

Your Nalto AI already talks to OpenRouter through n8n, with no streaming and no tools. For YOWA, one Supabase Edge Function does the job end to end, so answers stream in and use live stock and order data.

Tools it can call
  • search_products and get_product
  • check_stock per size
  • recommend_size from height, weight and fit, starting from the waitlist size
  • shipping_quote by state or country
  • track_order, which needs the order number and the email or phone, so nobody can look up someone else's order
  • policy_lookup for delivery, returns and care
  • handoff_to_human: a WhatsApp link carrying the chat ID
Rules it follows
  • Never states stock, prices or dates without checking with a tool.
  • No refund promises beyond the policy.
  • Hands over on payment disputes, damaged items, anger or anything legal.
  • Replies in the customer's language, Pidgin included, and keeps it short.
  • Every chat is logged and reviewable in the admin inbox.
  • The OpenRouter key lives only in Supabase function secrets.
